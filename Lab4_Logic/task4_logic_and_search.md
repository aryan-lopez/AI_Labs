# Task 4: Logic and Search

The planner combines logical reasoning with search. Logic checks which actions
are possible in a state and what state each action produces. Search chooses
which sequence of those applicable actions to explore until it reaches the
goal.

## Where each idea is used

### Logical reasoning

In `task2_planner.py`, `is_applicable` checks an action's preconditions against
the current state and static warehouse facts. An action with a missing
positive precondition, or with a forbidden fact present, cannot be applied.
For example, in `{RobotAt(A), PackageAt(A)}`, `PickUp(A)` is applicable, while
`Drop(C)` is not: the robot is not at `C` and is not holding the package.

Once an action is applicable, `apply_action` uses its effects to produce the
successor state. Applying `Move(A,B)` to the initial state removes
`RobotAt(A)` and adds `RobotAt(B)`, leaving `PackageAt(A)` unchanged.

### Search

`breadth_first_plan` explores the states generated by applicable actions. From
each state it considers the available actions, adds each newly reached state
to a FIFO queue, and checks whether a state satisfies the goal
`PackageAt(C)`. It stores parent links to recover the action sequence. Because
all actions count as one step, breadth-first search finds a plan with the
fewest actions when a plan exists.

## Planning process

```text
Current state
    ↓
Check action preconditions
    ↓ if satisfied
Apply action effects to generate a successor state
    ↓
Search over alternative applicable actions and resulting states
    ↓
Does a state satisfy the goal?
    ├─ Yes: return the action sequence leading to that state
    └─ No: continue searching; if no states remain, report no plan
```

For example, from the initial state the planner can apply `PickUp(A)` or
`Move(A,B)`. These actions lead to different successor states, so search must
consider alternatives. From the state after `PickUp(A)`, the robot can move to
`B`, then `C`, and drop the package there. The final state contains
`PackageAt(C)`, satisfying the goal.

## Think About It

**How do logical reasoning and search work together to produce a plan?**

Logic determines which actions are applicable in the current state and how
each action changes that state. Search explores sequences of those applicable
actions, comparing the resulting states with the goal. If a sequence reaches
the goal, its actions form a plan. Here, logic prevents invalid actions such
as dropping the package at `C` before the robot is there and holding it;
breadth-first search explores valid alternatives until it finds a sequence
that delivers the package to `C`.

In short, logic determines what is possible from each state, and search
determines which possible sequence to try.
